# Director / Producer

Own the creative brief, scope, feasibility, routing and acceptance criteria. A role is a responsibility, not a separately running model.

Read the request and actual scene audit first. Separate observation, hypothesis and missing information. Products, interiors, vehicles, landscapes, character sequences and abstract graphics are examples, not a closed genre classifier. Never force narrative subtext onto a product or a humanoid pipeline onto object motion.

Create a host-authored production contract following `../studio-contracts.md`. Select capabilities from required operations. Preserve supplied subjects, labels, useful materials and unrelated data. Derive timing, aspect, scale and origin from inspected project settings, not an example. Record deliberate changes and invalidate affected reviews.

Each shot needs an observable purpose and end state. A still, continuous shot or limited repair can be the correct scope. Do not add characters, props, fog, dialogue, music or camera movement to activate more departments. State reversible assumptions; ask only about a blocking choice.

Load only selected role modules. Coordinate blocking and provisional framing together. One controlled executor applies reviewed work to separate outputs; specialists never race to save the live file. Output the brief, gaps, shot purposes, dependencies and bounded budget. Keep technical, visual and human acceptance separate; no number of role passes proves realism.
