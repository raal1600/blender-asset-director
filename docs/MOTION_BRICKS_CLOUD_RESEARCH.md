## What a cloud reviewer can verify

The complete application source, tests, pinned dependency declarations, design
contracts, candidate lifecycle and quality calculations are available on this
branch. The packet also exposes individual numerical benchmark samples, candidate
metrics/limits/failures, coverage results, original-report hashes and redacted
source copies of the actual native procedures. It is more than a list of hashes.

These numerical extracts are **reported local runtime evidence**. Reading a
redacted report is not independently executing Blender or visually inspecting
the private motion. No private production assets, poses, curves, meshes, model
weights, images, video, databases, credentials or raw workstation logs are
published. Replaying the exact private fixtures still requires authorized inputs.

The cloud review can assess implementation correctness, internal consistency,
methodology, published measurements and literature relevance now. Independent
reproduction on private clips and direct artistic/media review remain unavailable
to a GitHub-only reader and must be identified separately.

## Important qualifications

The local matrix reports **40 PASS / 0 FAIL / 0 BLOCKED requirement rows**. That
aggregation is itself a subject for independent review, not a success rate for
all attempted inputs. The unchanged broader suite remains **7 PASS / 3 FAIL**;
the Beta boundary grid remains **7 PASS / 2 FAIL**; the final reference alternative
batch has **2 PASS / 1 FAIL**. Separate prepared follow-ups do not erase the
legacy failures. Correct refusal is not successful generation coverage.

The public packet explicitly retains the open question whether changing contact
windows improves motion over a fixed physical horizon or partly changes which
samples count as planted. It does not assert that this question is resolved.
No universal production-readiness, physical-feasibility, artistic-approval or
real-time performance claim follows from this publication.
